# 🚀 Velzewu1's Interactive Portfolio

Интерактивное портфолио-сайт с игрой, созданное с использованием React, Phaser.js и Tailwind CSS.

## ✨ Особенности

- 🎮 **Интерактивная игра** - Исследуйте мир с персонажем, используя WASD или стрелки
- 🎨 **Современный дизайн** - Темная тема с неоновыми эффектами и VHS фильтрами
- 📱 **Адаптивный интерфейс** - Работает на всех устройствах
- ⚡ **Быстрая загрузка** - Оптимизировано с Vite
- 🎯 **Интерактивные элементы** - Кликабельные объекты в игре
- 🌟 **Анимации частиц** - Красивый фон с движущимися частицами (particles.js)
- 🎭 **3D элементы** - Интеграция с Three.js для 3D эффектов
- 📝 **Типизированный текст** - Анимированный текст с эффектом печати
- 📺 **VHS эффекты** - Ретро фильтры для создания атмосферы

## 🛠️ Технологии

- **Frontend**: React 19, React Router DOM (HashRouter)
- **Игровой движок**: Phaser.js 3.88
- **3D графика**: Three.js
- **Частицы**: particles.js
- **Стилизация**: Tailwind CSS
- **Сборка**: Vite
- **Деплой**: GitHub Pages

## 🚀 Быстрый старт

### Установка зависимостей

```bash

```

```bash

```

### Сборка для продакшена

```bash
npm run build
```

### Предварительный просмотр сборки

```bash
npm run preview
```

### Деплой на GitHub Pages

```bash
npm run deploy
```

## 🎮 Игровые возможности

- **Управление**: WASD или стрелки клавиатуры
- **Анимации**: Плавные анимации персонажа в 4 направлениях
- **Камера**: Следует за персонажем
- **Интерактивность**: Кликабельные объекты с эффектами
- **Большой мир**: Исследуйте просторную карту
- **Физика**: Реалистичная физика движения

## 🎨 Дизайн

Проект использует темную цветовую схему с неоновыми акцентами и VHS эффектами:
- Основной фон: `#1A0A2E` (темно-фиолетовый)
- Акценты: `#0ff` (циан)
- Карточки: `#2A1240` (фиолетовый)
- Градиенты: От темно-фиолетового к пурпурному
- VHS фильтры: Контраст, насыщенность, яркость, оттенок

## 🔧 Настройка

### Изменение GitHub Pages URL

В `package.json` обновите поле `homepage`:

```json
{
  "homepage": "https://yourusername.github.io/your-repo-name/"
}
```

### Настройка Vite

В `vite.config.js` настройте базовый путь:

```javascript
export default defineConfig({
  plugins: [ react() ],
  define: {
    global: 'window'
  }
})
```

## 🎯 Особенности реализации

### HashRouter
Используется HashRouter для совместимости с GitHub Pages без необходимости настройки сервера.

### 3D интеграция
Проект поддерживает 3D элементы через Three.js для создания интерактивных визуальных эффектов.

### Частицы и анимации
Реализована система частиц через particles.js для создания динамичного фона и улучшения визуального опыта.

### VHS эффекты
Добавлены ретро фильтры через CSS для создания атмосферы старого телевизора.

### Адаптивность
Полностью адаптивный дизайн, который корректно работает на всех устройствах.
